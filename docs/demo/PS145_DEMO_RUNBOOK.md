This runbook outlines the rapid demonstration flow for judges and evaluators showing end-to-end functionality across Ingest, Feature Extraction, ML Inference, Canonical Normalization, Live SSE Streaming, and NVIDIA AI Investigation.

## Prerequisites & Terminal Setup
Open two terminal windows in the project root (`c:\Users\anika\OneDrive\Desktop\backend`):

### Terminal 1: Backend Server
```powershell
backend\.venv\Scripts\python.exe -m flask --app backend.app run --port 8000
```
*Expected Output:* Running on `http://127.0.0.1:8000`.

### Terminal 2: Pipeline / Attack Trigger
Leave Terminal 2 ready for curl or pipeline execution.

---

## 3-5 Minute Live Demonstration Script

### Minute 1: SOC Health & Real-Time Connection
1. Open browser to `http://localhost:8000/api/health`
   - Show `status: healthy` and `m4.available: true`.
2. Connect to the Live SSE Stream:
   - In browser or frontend: `http://localhost:8000/api/stream`
   - Show active connection heartbeat (`: ping - ...`).
3. View existing SOC alert statistics:
   - `http://localhost:8000/api/stats`

### Minute 2: Trigger Synthetic Attack Traffic (Meet M6 Integration)
In Terminal 2, trigger a safe background Port Scan simulation via the backend API:
```powershell
curl.exe -X POST http://localhost:8000/api/attack/start `
  -H "Content-Type: application/json" `
  -d '{"attack_type": "port_scan", "params": {"target": "127.0.0.1", "port_start": 80, "port_end": 100, "simulation": true}}'
```
Show response:
- `attack_id: "ATK-001"`
- `status: "running"`

Query attack status:
```powershell
curl.exe "http://localhost:8000/api/attack/status?attack_id=ATK-001"
```

### Minute 3: Real Ingest, Feature Extraction & Detection Pipeline (M1 -> M2 -> M3/M4)
Run the master pipeline orchestrator in Terminal 2:
```powershell
backend\.venv\Scripts\python.exe run_live_pipeline.py --mode synthetic --rate 10 --max-events 5
```
Highlight live log outputs:
1. **M1 Ingest**: Wire-speed synthetic packet emission.
2. **M2 Features**: Streaming aggregation into 66 canonical features (`FallbackPurePythonAggregator` auto-selected).
3. **M3/M4 Detection**: Krisha's Random Forest + Aayushman's 6-class classifier and Isolation Forest anomaly detector.
4. **M5 Alert Normalization**: Canonical `ALT-NNN` generation adhering to `shared/alert_schema.json`.
5. **SSE Broadcast**: Instantaneous emission of the alert to `/api/stream`.

### Minute 4: Inspect Live Alert Details (M5 & Canonical Schema)
In browser or Terminal 2, fetch the latest alert from the persistent store:
```powershell
curl.exe http://localhost:8000/api/alerts/ALT-001
```
Highlight for evaluators:
- `alert_id`: Sequential `ALT-NNN` format.
- `severity` & `confidence`: Validated and calibrated.
- `mitre`: Valid ATT&CK mapping (`T1046 Network Service Scanning`).
- `evidence`: Structured indicators of compromise (IOCs) and feature breakdowns.

### Minute 5: NVIDIA Nemotron 3.5 LLM AI Investigation
Trigger automated AI enrichment on the alert:
```powershell
curl.exe -X POST http://localhost:8000/api/ai/analyze/ALT-001
```
Highlight:
- `ai_summary`: Natural language technical executive summary generated by NVIDIA Nemotron 3.5.
- `risk_level` & `attack_stage`: Structured SOC analyst assessment.
- `recommended_actions`: Clear mitigation steps.
- Explainable defense: AI serves as an enrichment layer without replacing deterministic ML detection.
